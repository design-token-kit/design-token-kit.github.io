# Accessibility

## Our commitment

The Design Token Kit website aims to be usable by as many people as possible.
We consider accessibility during design, implementation, and review.

The project aims to provide:

- Semantic HTML and meaningful page structure.
- Keyboard-accessible navigation and controls.
- Visible focus states and readable color contrast.
- Responsive layouts across supported viewport sizes.
- Text alternatives for informative images and icons.

## Supported environments

The website is intended for current versions of Chrome, Edge, Firefox, and
Safari on supported desktop and mobile operating systems.
Accessibility may vary with browser extensions, custom styles, assistive
technology settings, or older browser versions.

## Known limitations

The project has not completed a formal accessibility audit.
Some pages, generated examples, or interactive controls may still need
improvement.
This document does not claim conformance to a specific accessibility standard.

## Report an accessibility barrier

If you encounter an accessibility problem, open a GitHub issue with:

- The page URL or affected component.
- A description of the barrier and the expected behavior.
- The browser, operating system, and assistive technology, if relevant.
- Steps to reproduce the problem.

Please avoid including private or sensitive information in a public issue.
The project team will review accessibility reports and prioritize fixes
alongside other product work.
